# v2.0-youxin

Release date: 2026-11-05

This release preserves The Pipe Camera firmware for the current Youxin
ESP32-S3 / OV2640 board before migration to another manufacturer. The existing
camera pin mapping and board behavior are retained.

## Included functionality

- JPEG capture and HTTP POST streaming with configurable resolution, quality, and frame rate.
- WiFi provisioning, persistent network settings, authenticated web UI, and internationalization.
- WS2812B strip control with configurable physical strip length and evenly spaced active LEDs.
- Onboard status LED, factory reset, and optional HX711 scale calibration and weight metadata.
- Python companion server and camera viewers.

The firmware version reported at boot and in the web UI is now `v2.0-youxin`
(previously `3.5.0`), matching the release tag and identifying the board baseline.

## Build and validation

Firmware compilation passed with Arduino ESP32 core 3.3.11 and
`esp32:esp32:esp32s3:PSRAM=opi` (other board options at their defaults):

```sh
arduino-cli compile --fqbn esp32:esp32:esp32s3:PSRAM=opi v3_ino_2
python3 -m unittest discover -s tests -v
```

Libraries: ArduinoJson 7.4.3, ESP Async WebServer 3.12.0, Async TCP 3.5.0,
and Adafruit NeoPixel 1.15.5.

- Firmware uses 1,156,475 bytes of program storage and 60,020 bytes of global RAM.
- Both host tests passed: LED controller/persistence checks and embedded JavaScript syntax.
- No on-device smoke test was performed for this release.

This is a source release; use the Arduino setup instructions in the README to
build and flash the current board. Firmware for the replacement manufacturer's
board will require separate pin mapping and hardware validation.
