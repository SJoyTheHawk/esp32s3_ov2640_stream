ESP32-S3 CAMERA VIEWER - WINDOWS TRANSFER PACKAGE

1. Copy this entire folder to the Windows PC. Keep the folder structure intact.
2. Install Python 3.10 or newer from https://www.python.org/downloads/windows/.
3. Run "Install Dependencies.bat" once.
4. Run "Professional Viewer.bat".
5. In the viewer Settings dialog, enter the ESP32 stream URL, username, and
   password. Captures are saved under the captures folder by default.

The package is self-contained and does not include Python, camera firmware,
or captured media. Internet access is needed only while installing packages.
